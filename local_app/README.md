# 学习通作业提醒本地版 App

这是当前 GitHub 仓库实际开源的版本，位于 `local_app`。它是一个本地优先的 Flutter App，不依赖自建后端。

当前版本：1.0.5

## 功能

- 使用学习通账号密码登录并同步作业/考试。
- 支持数你最灵账号登录并同步作业。
- 数你最灵学校列表自动获取，支持按学校名称或学校代码关键字筛选。
- 支持自定义自动同步分钟数；过快同步会增加耗电量和网络请求次数。
- 自动同步会更新作业和最新截止时间，并在截止时间变化后重新安排提醒。
- 自动同步间隔采用小卡片式选择，不再使用拥挤的椭圆分段控件。
- 学习通考试会合并到“作业”页，不再单独提供手动添加考试入口。
- 只显示未完成作业；已提交待批阅、已完成、completed、已互评作业会被过滤，未完成互评作业会保留。
- 支持作业详情、返回主页、手动标记完成。
- 手动标记完成的作业会本地隐藏，后续刷新不会重新出现。
- 提供本地同步状态页和友好刷新提示。
- 支持自定义提醒时间，可按“几小时几分钟”精确到分钟设置、删除并保存多个提醒规则。
- 支持本地系统通知、锁屏提醒、精确闹钟和开机后恢复已安排提醒。
- 通知文案会显示“还剩 4 天 3 小时 5 分钟截止”这类易读格式。
- 提醒设置页提供通知权限、精确闹钟、锁屏提醒、后台与自启动的系统设置入口。
- 支持 Android 桌面小组件，显示近期待完成作业、课程名和剩余时间。
- 小组件点击可通过 deep link 直接进入对应作业详情。
- “关于应用”包含版权、MIT License 和 GitHub 源码入口。

## 隐私与边界

- 学习通、数你最灵账号密码和作业数据只保存在本机，不会上传到任何自建服务器。
- 凭证通过 Flutter 安全存储保存到 iOS Keychain / Android Keystore。
- 不实现验证码绕过、风控绕过或逆向破解加密保护。

## 使用指南

### 安装

1. 在 GitHub Release 页面下载最新版 APK。
2. 在 Android 手机上打开 APK，根据系统提示允许安装。
3. 首次打开 App 后，授予通知权限。
4. 进入“提醒”页，按需要打开通知权限、精确闹钟、锁屏提醒、后台与自启动等系统设置。

### 登录和同步

1. 选择学习通或数你最灵登录。
2. 登录数你最灵时，先搜索并选择学校，再输入学号和密码。
3. 到“同步”页点击刷新作业。
4. App 会同步未完成作业和最新截止时间，并重新安排提醒。
5. 自动同步可选择 15 分钟、30 分钟、1 小时、关闭，也可以输入自定义分钟数。建议不要低于 15 分钟。

### 作业和提醒

1. “作业”页只显示未完成作业。
2. 点击作业进入详情，可以返回主页，也可以手动标记完成。
3. 手动完成后的作业会本地隐藏，后续刷新不会重新出现。
4. “提醒”页可以选择预设提醒，也可以输入几小时几分钟的自定义提醒时间。
5. 点击保存后，会重新安排所有未完成作业的本地通知。

### 桌面小组件

1. 长按 Android 桌面空白区域，选择“小组件”。
2. 添加“学习通作业提醒”小组件。
3. 小组件显示近期待完成作业、课程名和剩余时间。
4. 点击小组件里的作业可直接打开对应详情页。

## v1.0.5 更新

- 新增数你最灵作业提醒支持。
- 数你最灵登录页支持学校列表自动加载和关键字筛选。
- 学习通考试合并到“作业”页，移除自定义添加考试入口。
- 已提交待批阅、已完成和 completed 状态作业会从列表中过滤。
- 登录失败会直接显示明显提示，不需要再次输入触发刷新。
- Android 版本为 `versionName=1.0.5`、`versionCode=16`。

## v1.0.4 更新

- 自动同步时间选择改为独立小卡片，解决手机上椭圆分段控件拥挤的问题。
- 新增提醒权限入口，用户可以看到并跳转管理通知、精确闹钟、锁屏提醒、后台与自启动。
- 提醒通知显示易读剩余时间，并支持锁屏展示。

## 开发运行

```powershell
cd D:\code\study_assistant\local_app
flutter pub get
flutter test
flutter analyze
flutter run
```

## 构建 APK

```powershell
cd D:\code\study_assistant\local_app
flutter build apk --release
```

如需使用本机 release keystore 签名，请在本地保管 `.jks` 文件，不要提交到 Git。

## 目录

- `lib`：Flutter 业务代码。
- `android`：Android Runner、小组件、原生打开外部链接 MethodChannel。
- `ios`：iOS Runner 和 WidgetKit 扩展骨架。
- `test`：解析、过滤、同步合并、提醒规则和 deep link 测试。
