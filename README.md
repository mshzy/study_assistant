# 学习通作业提醒

本仓库只维护 [`local_app`](local_app) 中的 Flutter 本地版应用。登录、作业同步、提醒和桌面小组件的代码都在该目录；应用不依赖本仓库中的自建后端。

功能、隐私说明、运行和构建步骤见 [local_app/README.md](local_app/README.md)。源码版本以 [local_app/pubspec.yaml](local_app/pubspec.yaml) 为准，安装包从 [GitHub Releases](https://github.com/mshzy/study_assistant/releases) 获取。
